# Shared audio library

Place your audio files in this folder. MP3 files are the safest choice for browser playback.

Name each file using this format:

```text
Title - Artist.mp3
```

Double-click `generate-audio-playlist.command` in this folder after adding, removing, or renaming audio files. It scans this folder, updates `playlist.js`, and makes the new list available to Winamp automatically.

Tracks by Robert Wei appear first. Tracks within each group are sorted by title.

Pages in Vision, Works, and SWE can load the same shared list from `/content/audio/playlist.js`.
