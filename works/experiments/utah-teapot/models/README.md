# Test object assets

The additional test objects are local copies of selected models from Kenney's official asset packs. Both packs are released under the [Creative Commons CC0 1.0 Universal license](https://creativecommons.org/publicdomain/zero/1.0/).

## Cube Pets

- Source: [Kenney Cube Pets](https://kenney.nl/assets/cube-pets)
- License: CC0 1.0 Universal
- Included license: `licenses/kenney-cube-pets.txt`
- Local files: `animal-bunny.glb`, `animal-monkey.glb`, `Textures/colormap.png`
- Original archive paths: `Models/GLB format/animal-bunny.glb`, `Models/GLB format/animal-monkey.glb`, `Models/GLB format/Textures/colormap.png`

## Furniture Kit

- Source: [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit)
- License: CC0 1.0 Universal
- Included license: `licenses/kenney-furniture-kit.txt`
- Local files: `chair.glb`, `toilet.glb`, `pottedPlant.glb`
- Original archive paths: `Models/GLTF format/chair.glb`, `Models/GLTF format/toilet.glb`, `Models/GLTF format/pottedPlant.glb`

The models are loaded only when selected. Their original materials are replaced at runtime by the experiment's shared material so texture mapping, filtering, and reflection controls behave consistently across objects.
